# WA Rental Pro

Professional automated rental-management SaaS starter.

Included:
- Responsive modern dashboard
- User/admin roles
- JWT authentication
- Automated rental expiration
- Automatic device status synchronization
- Balance ledger
- Rental history
- Admin analytics
- Audit log
- REST API
- SQLite persistence

Run:
npm install
npm start

Open http://localhost:3000

Demo admin:
admin@example.com
change-this-password

For production, change JWT_SECRET and the demo password.
This project does not implement OTP interception, account takeover,
spam automation, or bypassing third-party security controls.
